# Procedural material textures

The "construction materials" identity (wooden sign buttons, corkboard listings,
paper flyers, clipboard dialogs) is drawn from procedurally-generated textures,
baked once to small WebP assets in `public/img/`. No external image assets, no
licensing — everything is generated by WebGL fragment shaders in these files.

## Files

- `gen-wood.html` — wooden sign board (fBm grain → annual rings → lighting,
  knots, nails, rough silhouette). Exports `wood-sign.webp`.
- `gen-materials.html` — cork (`cork.webp`), paper (`paper.webp`) and concrete
  (`concrete.webp`) surfaces.

## Regenerating an asset

Open the generator in a browser and read the canvas out as WebP:

```js
// in the page console, after it renders:
copy(document.querySelector('canvas').toDataURL('image/webp', 0.9))
```

…then decode the base64 into `public/img/<name>.webp`. Tune the shader uniforms
/ colour ramps in the `<script id="fs">` block first. Keep the output small
(≤ ~45 KB) — these load site-wide, so watch the perf budget.

The baked assets currently in use:

| Asset | Size | Used by |
|-------|------|---------|
| `wood-sign.webp` | ~36 KB | `.ps-btn` (primary buttons) |
| `cork.webp` | ~45 KB | `.ps-cards` (listing corkboard) |
| `paper.webp` | ~11 KB | `.ps-card`, `.ps-dlg__body`, `.ps-toast` |
| `concrete.webp` | ~13 KB | reserved (section backgrounds) |
